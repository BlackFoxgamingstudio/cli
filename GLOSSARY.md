# Project Glossary

This document defines standard terminology used across this microservice to ensure human developers and AI context windows remain perfectly aligned.

| Term | Definition |
|------|------------|
| **PDLC** | Product Development Life Cycle. |
| **Agent** | An autonomous AI script or LLM orchestrator acting on the codebase. |
| **Microservice** | A decoupled, independently deployable software component. |
| **SAST** | Static Application Security Testing (e.g., CodeQL). |
| **SBOM** | Software Bill of Materials. |
