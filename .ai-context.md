# AI Context & Directives

This file provides architectural boundaries, constraints, and context for any AI agents (e.g., CodeRabbit, Sweep, or local LLMs) interacting with this microservice repository.

## 1. Domain Boundaries
- **Service Name:** Cli
- **Responsibility:** Handles A secure, standards-compliant Python microservice managing domain pipelines..
- **Anti-Patterns:** Do not introduce direct database calls to other microservices; always use the documented API boundaries or message queues.

## 2. Code Standards
- **Style:** Strictly adhere to the linters defined in the CI pipeline.
- **Testing:** 100% patch coverage is required. Do not submit PRs without accompanying tests.
- **Documentation:** Ensure all new functions, classes, and endpoints include standard docstrings or JSDoc comments.

## 3. Review Process
- Before submitting a patch, ensure that `make lint` and `make test` pass locally.
- Keep changes atomic. Do not refactor code outside the immediate scope of the issue.
